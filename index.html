CPEN 321 M1 App

This is a student project built for CPEN 321 (Software Engineering) at the University of British Columbia. It is an Android app backed by a server running on a cloud virtual machine.

Signing in

The app uses Google Sign-In so you can log in with your existing Google account. We only request basic profile information (your name, email address, and profile picture) to sign you in for your current session. Nothing is saved permanently.

About this project

This app is developed for educational purposes only as part of a course assignment. It is not a commercial product and is not affiliated with or endorsed by Google.
